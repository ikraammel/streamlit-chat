# Streamlit Chat

A chat application project built around Streamlit.

## Repository overview

This repository is part of my software engineering portfolio. It contains the implementation and supporting project files for **Streamlit Chat**.

## Getting started

Clone the repository:

```bash
git clone https://github.com/ikraammel/streamlit-chat.git
cd streamlit-chat
```

Review the source files and dependency manifests for the project's runtime and configuration requirements.

## Project structure

Browse the source folders in this repository to explore the implementation. For projects with separate frontend and backend components, configure and run each component independently.
